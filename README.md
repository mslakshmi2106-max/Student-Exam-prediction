 Student Performance Prediction

 Project Overview

This project uses Machine Learning to predict student performance based on academic and personal factors. The dataset is analyzed, preprocessed, and used to train a Random Forest Classifier model.

 Objectives

* Analyze student performance data.
* Predict student pass/fail status.
* Evaluate model accuracy.
* Visualize data using charts.

Technologies Used

* Python
* Pandas
* Matplotlib
* Scikit-learn
* Google Colab

Features

* Data preprocessing and cleaning.
* Label encoding for categorical data.
* Random Forest Classification.
* Accuracy evaluation.
* Histogram and Bar Chart visualization.

 Output

* Student performance prediction.
* Model accuracy score.
* Data visualization charts.

Conclusion

This project demonstrates how Machine Learning can be used to analyze student data and predict academic performance effectively. It helps in identifying student outcomes and supports data-driven decision-making in education.
